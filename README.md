# Seasonal Agriculture Performance Analysis

## Project Overview

Seasonal Agriculture Performance Analysis is a Data Analytics project that
examines agricultural performance across different seasons, crops,
environmental conditions, resource usage, and economic factors.

The project aims to identify seasonal patterns, trends, relationships,
variations, and differences in agricultural performance.

## Objectives

- Explore and understand the agricultural dataset
- Clean and prepare the data
- Compare agricultural performance across seasons
- Analyze crop performance
- Study environmental factors and their relationship with yield
- Analyze resource and irrigation usage
- Study cost, revenue, and profit
- Perform correlation and statistical analysis
- Identify unusual patterns and outliers
- Provide data-driven recommendations

## Dataset

The dataset contains:

- 4,000 records
- 28 attributes

The dataset includes information about:

- State and District
- Crop and Season
- Farm Area
- Rainfall
- Temperature
- Humidity
- Sunlight
- Soil conditions
- Nutrient usage
- Fertilizer and pesticide usage
- Irrigation
- Yield and production
- Market price
- Cost, revenue and profit
- Water usage and efficiency
- Disease and pest risk
